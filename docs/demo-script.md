# Camera demo script

Record 2–3 minutes with your camera visible. Use the actual local application, not a fabricated recording. Keep an already-generated essay and artifact available so slow CPU generation does not consume the entire video.

0:00–0:20 — Introduce the problem: product teams need trustworthy advice and reusable work from a large podcast archive. Explain the question → evidence → action workflow.

0:20–0:55 — Show Ollama selected and Connected. Ask: “How does Teresa Torres recruit customers for weekly interviews using Calendly?” Open a source citation and the passage behind the answer.

0:55–1:15 — Ask a follow-up in the same conversation. Explain that each conversation has independent persisted context. Open another saved conversation to show history.

1:15–1:45 — Open a completed Ship 30 essay. Show the word count, readable sections and citations. Explain that writing principles are in a reusable skill file, not a one-off prompt.

1:45–2:15 — Open an HTML artifact alongside the chat. Toggle source view and back. Explain that generated HTML is sanitized and rendered in an isolated, scriptless iframe.

2:15–2:40 — Explain one trade-off: lexical retrieval avoids a second local embedding model and stays inspectable, but paraphrase recall can be weaker. Mention no automatic cloud fallback.

2:40–2:55 — Show the README startup command and test results. State what you would add for production: authentication and measured retrieval improvements.

Upload the real camera-enabled recording to YouTube. Check the link in a signed-out browser before submitting. Do not include API keys, environment files, or personal desktop notifications.
